# UniQueue — University Queue UI Prototype

A lightweight, multi-page interface concept for a university queue system. This repository contains standalone HTML pages for the landing page, login, queue status, and staff dashboard.

## Pages

- **index.html** — landing page
- **login.html** — sign-in screen
- **queue-status.html** — queue status view
- **dashboard.html** — dashboard view
- **style.css** — shared styles

## Run locally

Clone the repository and open **index.html** in a browser. No build step is required.
